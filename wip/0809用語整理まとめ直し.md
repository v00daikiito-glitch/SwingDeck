## 2. どこでも使う共通キー


| キー                  | 意味            | 取りうる値                                       | 置く場所                                                             | paramsに入れる？                 |
| ------------------- | ------------- | ------------------------------------------- | ---------------------------------------------------------------- | --------------------------- |
| `timeframe`         | 足             | `"daily"` / `"weekly"` / `"monthly"`        | 辺の indicator、metric_json、baseline indicator、`calculate_all` のトップ | **入れない**                    |
| `lookback`          | 何本前の確定足か      | 整数（初期 0）                                    | 工房の indicator 辺。metric にある場合も外側                                  | **入れない**                    |

| `params`            | その kind 固有の注文 | kindごとに定義（パック2）                             | indicator／metric／baseline indicator／need_ でオブジェクトを書くとき           | これが本体                       |

| `source`            | 価格列           | `"close"` / `"open"` / `"high"` / `"low"` 等 | params内（MA系など）                                                   | 入れる                         |
| `period`            | 期間・本数         | 整数                                          | params内                                                          | 入れる                         |

### 2-2. Bollinger（本編に共通定義あり）


| 関数                              | 引数                                            | params                                                | need_               |
| ------------------------------- | --------------------------------------------- | ----------------------------------------------------- | ------------------- |
| `calculate_bollinger_bands`     | `(価格系列, period, multiplier, ma_type, source)` | `{ period, multiplier, ma_type, source, band }`       | オブジェクト1つ（または複数なら配列） |
| `calculate_bollinger_bandwidth` | `(価格系列, period, multiplier, ma_type, source)` | `{ period, multiplier, ma_type, source }`（**bandなし**） | オブジェクト              |


`band`（関数引数ではない）: `"both"` / `"upper"` / `"lower"`  

- チャート need: 通常 `"both"`  
- 工房・baseline で1本: `"upper"` or `"lower"`  
`ma_type` 例: `"SMA"` / `"EMA"`（Catalog kind ではない）

### 2-3. MACD（関数を順に渡す。関数名は略さない）

```text
calculate_macd_line
  → calculate_macd_signal
    → calculate_macd_hist
      → calculate_macd_velocity
```


| 関数                        | 工場の引数（実装口）                                          | ユーザーが注文する params（オブジェクト形）                                                                               | need_         |
| ------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------- |
| `calculate_macd_line`     | `(価格系列, fast_ema_period, slow_ema_period, source)`  | `{ fast_ema_period, slow_ema_period, source }`                                                          | オブジェクト        |
| `calculate_macd_signal`   | `(macd_line, signal_ema_period)`                    | `{ fast_ema_period, slow_ema_period, signal_ema_period, source }` ※途中の line は params に書かない              | オブジェクト        |
| `calculate_macd_hist`     | `(macd_line, macd_signal)`                          | `{ fast_ema_period, slow_ema_period, signal_ema_period, source }`                                       | オブジェクト        |
| `calculate_macd_velocity` | `(macd_hist, smooth_ema_period, velocity_lookback)` | `{ fast_ema_period, slow_ema_period, signal_ema_period, smooth_ema_period, velocity_lookback, source }` | オブジェクト（本編例あり） |


`need_MACD_velocity` だけのとき: 内側で line→signal→hist→velocity を関数名どおり実行。戻り値に途中も要るときだけ各 need_ を追加。

`velocity_lookback` ≠ 辺の `lookback`。

本編 need 例:

```json
"need_MACD_velocity": {
  "fast_ema_period": 12,
  "slow_ema_period": 26,
  "signal_ema_period": 9,
  "smooth_ema_period": 5,
  "velocity_lookback": 1,
  "source": "close"
}
```

### 2-4. Deviation（現状と案を並べる）


|            | 現状（本編）                                                  | 案（接続を揃える）                             |
| ---------- | ------------------------------------------------------- | ------------------------------------- |
| 関数形        | `calculate_deviation(価格データ, params)`                    | `calculate_deviation(指定1の数値, 指定2の数値)` |
| 式          | いまの株価が、params で指定した基準から何％か（いまの株価は第1引数側）                 | `(v1−v2)/v2×100`                      |
| params     | `{ target, period?, value? }`                           | `{ left: <指定>, right: <指定> }`         |
| `target` 値 | `"SMA"` / `"EMA"` / `"horizontal_line"` / `"bollinger"` | **やめる方向**（`"SMA"` は Catalog とも一致しない）  |
| need_      | 上記オブジェクトの配列                                             | left/right オブジェクトの配列                  |
| 類型B        | 旧関数へ渡すと書いてある                                            | left/right をそれぞれ数値にして同じ式              |


指定（案）の種類例:


| spec_type      | 中身                                   |
| -------------- | ------------------------------------ |
| `number`       | `value`                              |
| `price`        | Price（足・何本前はその指定の中に持つ）               |
| `snapshot`     | Snapshot                             |
| `eval_price`   | EvalPrice                            |
| `indicator`    | kind + timeframe + params + lookback |
| `baseline_ref` | role（＋U1で数値1つにする）                    |


数字同士も可。種類を狭く固定しない。

## 4. need_ 値の形（現状ルール）

## 3. JSONツリー



### 3-A. `settings_json`（chart_settings）

```text
settings_json
├─ MA[]                         … 枠1〜10すべて保持
│   └─ { line_number, period, visible, legend_on }
├─ EMA[]                        … 枠1〜3すべて保持

    ├─ RSI { period, visible }

```

※表示設定。baseline の期間を、計算のたびにここから取り直さない。

### 3-B. `conditions_json`（user_filters）

```text
conditions_json  … 次のいずれか1つの根
│
├─ node_type: "group"
│   ├─ logical_operator: "AND" | "OR"
│   ├─ is_active: bool
│   └─ rules[] (≥2)
│       └─ (再帰) group | filter_reference | inline_rule
│
├─ node_type: "filter_reference"
│   ├─ filter_id → user_filters.id（elementのみ）
│   └─ is_active
│
└─ node_type: "inline_rule"
    ├─ left: <辺>
    ├─ operator: "<"|">"|"<="|">="|"="|"GC"|"DC"
    ├─ right: <辺>
    └─ is_active

<辺> side_type 分岐:
├─ "number"    → value
├─ "indicator" → kind, timeframe, params, lookback
│                 kind ∈ IndicatorCatalog
│                 timeframe ∈ daily|weekly|monthly
│                 params … kind固有（パック2）
│                 lookback … 整数（初期0）
└─ "baseline"  → role ∈ entry|take_profit|stop_loss
                  （銘柄はJSONに書かない。数値1つへの決め方はU1未決）
```

element: 根は inline_rule 1本のみ。  
condition: 根は式（group可）。完成品の中に完成品は不可。

保存エラー: number同士／GC・DCで片側number／groupの子<2／必須欠け。
