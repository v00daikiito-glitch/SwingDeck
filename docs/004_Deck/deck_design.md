=================================================================
デッキ画面設計（データ更新トリガー）
=================================================================
※本書は当面、デッキ（分割チャート一括表示）表示時のデータ更新呼び出しを定義する。
※分割レイアウト・チャート描画の詳細は後続で追記する。
※日足・気配値の取得ロジック本体は 01_Data_Layer.md【DailyBarService】を正とする。
※監視銘柄（user_watchlist）とプレイリストの関係は 00_Master_Design.md 3-E を正とする。


-----------------------------------------------------------------
1. この画面でやること（データ更新）
-----------------------------------------------------------------
【きっかけ】
・サイドメニューやリンク等でデッキ画面を開いたとき

【対象】
・user_watchlist 全体（デッキに今出している銘柄だけではない）
  - 日足更新も気配値更新も、対象は監視銘柄名簿（user_watchlist）

【呼び出す処理（順）】
  1. DailyBarService.update_daily_bars_for_watchlist(...)   … 日足
  2. DailyBarService.update_snapshots_for_watchlist(...)  … 気配値
  3. indicators.calculate_all 等で表示に必要な計算を行う
  4. 分割チャートを描画する

【前提】
・スキップ判定あり（確定日足が揃っている／同一時間枠内の気配値済みは fetch しない）
・定時の強制一括取得はしない
・indicators の計算結果の永続キャッシュは当面しない（都度計算でよい）


-----------------------------------------------------------------
2. やらないこと（この画面の更新では）
-----------------------------------------------------------------
・cleanup_stale_viewed_symbols（アプリ起動時のみ）
・touch_last_viewed（個別チャート側）
・「デッキに表示中の銘柄だけ」を更新対象にする
  （更新対象は常に user_watchlist 全体）
