※列の表示・ソート・列ごとの抽出（extract_chips）は工房の対象外。00_Master_Design.md の 3-D および「指標・列・フィルターの関係」を正とする。


-----------------------------------------------------------------
1. この画面でできること
-----------------------------------------------------------------
【作る・直す】
・エレメント（比較まで含んだ1本の条件）を新規作成・編集・削除する
・完成品（式）を新規作成・編集・削除する
  - 完成品は、直書きでルールを並べて式を組むのが基本
  - 保存済みエレメントを、式の一部としてポン付けできる（必須ではない）

【使う（適用する）】
・オレンジ（場の抽出フィルター）に、エレメントまたは完成品を1つ指定する
・水色（銘柄チャートのシグナル網掛け）に、エレメントまたは完成品を1つ指定する
・オレンジ／水色にエレメントを付けたとき、裏で完成品を自動作成しない

【やらないこと（この画面では）】
・プレイリスト列の追加・削除・並べ替え
・列ごとの抽出（extract_chips）の操作
・user_metrics の作成・編集（user_metrics はプレイリスト列の計算定義。工房では作らない・触らない）

-----------------------------------------------------------------
2. 完成品を作る／直す
-----------------------------------------------------------------
保存先：
・user_filters に1件保存する
・filter_type は condition（完成品）
・式の中身は conditions_json に入れる（形の詳細は 00_Master_Design.md 3-B／3-F を正とする）

画面でやること：
・名前を付ける（filter_name）
・ルールを1本以上並べて式を作る
・保存する／既存の完成品を開いて直す／削除する

式の組み立て（基本）：
・基本は「直書きルール」を並べる
・1本の直書きルールは、左辺・比較・右辺の3つで表す（詳細は 3-F）
・ルールとルールのあいだは AND（かつ）または OR（または）でつなぐ
・カッコ（グループ）で優先順位を付けられる（詳細は 3-F）
・各ルールには ON/OFF を付けられる（is_active。詳細は 3-B／3-F）

エレメントの使い方（任意）：
・保存済みエレメントを、式の1ブロックとして差し込める
・エレメントが無いと完成品が作れない、ということではない
・差し込んだあとも、そのブロックを ON/OFF できる

数式表示と日本語表示：
・同じ保存データに対して、画面上の見せ方だけ切り替えられる（詳細は 3-F）
・保存する JSON の形は1種類のまま変えない

やらないこと：
・完成品の中に、別の完成品を入れない
・直書きルールやエレメントの作成時に user_metrics を作らない
・保存のたびにオレンジ／水色へ自動で付けない（付ける操作は別）


-----------------------------------------------------------------
3. これから書く区切り
-----------------------------------------------------------------
・エレメントを作る／直す
・一覧（エレメント／完成品）
・オレンジ／水色への指定
